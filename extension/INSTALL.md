# Install Better SGY

> **Full install guide (with Demo + all three looks): [EDITIONS.md](./EDITIONS.md)**
> 
> **Short version: [root README](../README.md)**

Two downloads on the [Releases page](https://github.com/saptarshighosh10-oss/better-sgy/releases):

| File | What it is |
|---|---|
| `Better-SGY-Demo.zip` | Try it with fake data — no Schoology account needed |
| `better-sgy-extension-1.0.0-chrome.zip` | Real extension, reads your actual grades |

**Install steps (same for both):**

1. Unzip the file.
2. Go to `chrome://extensions`.
3. Turn on **Developer mode** (toggle, top-right).
4. Click **Load unpacked** → pick the unzipped folder.

Runs locally — nothing leaves your device.
