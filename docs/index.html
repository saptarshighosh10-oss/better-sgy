How it came together

A small project that got a little out of hand.

Better SGY started as a personal fix for a daily annoyance and grew into something worth sharing. Here is the honest version of how it got here.

01 — The problem

Checking grades was a chore

Schoology has the numbers, but finding them means digging through a cluttered gradebook. Wanting to know "how am I doing right now" turned into clicking around three menus and reading a wall of rows.

02 — The build

An overlay, not a rebuild

Rather than ask anyone to move their data, the extension reads your own logged-in Schoology session and draws a cleaner view on top of it. Install it and that is the setup. The numbers come from the same place they always did.

03 — The exploration

Four looks, all real

Picking a single design felt like guessing, so four complete directions got built and made fully interactive. Each one is a different answer to the same question: what should a gradebook feel like? You can open all four below.

04 — Where it is now

A demo and the real thing

There is a demo with sample grades that needs no login, so you can poke around in seconds. And there is the real version that reads your actual Schoology once you install it. Both are below.

What it actually does

Built around the things you check most.

No grand claims. These are the parts that are shipped and working today.

Every class at once

A clean overview of all your courses with the current grade and which way it is heading. The whole term in one screen.

Grade-over-time graphs

Watch a grade move across the term. History builds as new grades post, so you can see a real trend instead of a single number.

Notifications that find you

Get a desktop notification when a grade changes, something gets graded, or a new assignment shows up. It can check in the background even with no Schoology tab open.

Per-course gradebooks

Open any class for the full breakdown, including weighted categories, so you can see exactly what is pulling your grade up or down.

Submit assignments

Hand in work to Schoology from inside the extension. Text or a file, and it creates a proper revision, the same as the site would.

The rest of the day

Assignments list, calendar, announcements, and course materials are all here too, so the extension covers more than just the numbers.

Log into Schoology the way you normally do, and the extension shows your actual grades. The gradebook data stays in your browser; it is not uploaded anywhere.

Download the extension better-sgy-extension-1.0.0-chrome.zip

Installing it (about two minutes)

1

Unzip the download

Double-click the .zip you got from Releases. You will end up with a folder. Leave it somewhere you will not delete by accident.

2

Open extensions

In Chrome, go to chrome://extensions in the address bar and press enter.

3

Turn on Developer mode

Flip the Developer mode switch in the top-right corner of that page.

4

Load unpacked

Click Load unpacked, pick the folder you unzipped, and it is in. Open Schoology to see it.

For now it installs through Chrome's developer mode, which is normal for an extension that is not on the Web Store yet. If a step looks unfamiliar, the GitHub Releases page has the same instructions.
