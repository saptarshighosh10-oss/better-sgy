# Install Better SGY

> **Full install guide (with the Demo + all four looks): [EDITIONS.md](./EDITIONS.md)**
> 
> **Short version: [root README](../README.md)**

Better SGY doesn't replace Schoology — it redraws your real Schoology page on
top of itself. Same login, same grades, a cleaner view drawn over the page you
already use.

**Start with the Demo** — it shows that overlay with sample grades, no account
needed. Two downloads on the [Releases page](https://github.com/saptarshighosh10-oss/better-sgy/releases):

| File | What it is |
|---|---|
| `Better-SGY-Demo.zip` ⭐ | Start here. The overlay with fake data — no Schoology account needed |
| `better-sgy-extension-1.0.0-chrome.zip` | The real extension — draws over your Schoology with your actual grades |

**Install steps (same for both):**

1. Unzip the file.
2. Go to `chrome://extensions`.
3. Turn on **Developer mode** (toggle, top-right).
4. Click **Load unpacked** → pick the unzipped folder.

Runs locally — nothing leaves your device.
