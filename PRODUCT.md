# Product

## Register

product

## Users

Students (primarily the builder, potentially other Schoology users) who are stuck using a bland institutional gradebook and want something that actually reflects their personality. They open this while studying, between classes, or when they need to know where they stand — the context is personal and frequent, not formal.

## Product Purpose

Better SGY replaces the Schoology gradebook UI with a personal, interactive grade dashboard. It pulls the same data but presents it in a way that feels crafted and expressive rather than institutional. Success looks like: checking your grades actually feels good, the data is immediately readable, and the interface feels like yours — not like a school's.

## Brand Personality

Playful, personal, expressive. The themes and mascots (Invincible characters, Billy Butcher preset, monochrome modes) are a first-class feature — not decoration on top of a dashboard, but the point of the product. The interface should feel like it belongs to whoever is using it.

## Anti-references

- Generic school portals (Schoology, Canvas, Blackboard) — the institutional gray, enterprise form-field aesthetic, zero personality
- Sterile SaaS dashboards — navy + white analytics tools, hero metric cards, ghost-card grids, "Updated 12 min ago" as a design centerpiece
- Cluttered gradebook apps — walls of numbers with no breathing room, no hierarchy, no delight

## Design Principles

1. **Themes are expression, not theming** — the preset system is a personality system. Every theme should feel fully committed, not like a color swap on a generic shell.
2. **Data readable at a glance** — grades tell a story. The hierarchy should make the important number (current grade, trend, missing) land instantly.
3. **Personal over universal** — built for a specific person first. Quirky choices (mascots, screensavers, show-inspired presets) are features, not bugs.
4. **Make checking grades feel good** — the moment of opening the app should have some pleasure in it. Motion, personality, and craft matter here.
5. **Contrast the institution** — at every design decision, ask if this looks like it came from a school portal. If yes, reconsider.

## Accessibility & Inclusion

WCAG AA minimum (4.5:1 body contrast). Reduced motion already implemented via `.reduce-motion` class. All themes should maintain readable contrast; the dark themes in particular need checking against body text minimums.
